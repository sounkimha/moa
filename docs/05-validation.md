## 서버 테스트 상세

1. 비로그인 사용자의 비공개 snapshot 접근 차단.
2. 예시 메타데이터 자동 입력과 임의 URL 수동 fallback.
3. 음수 금액·제외 카테고리·잘못된 날짜·부족 예산 차단.
4. 자기 요청 제안·다른 사람 일정 사용·기간 불일치 차단.
5. 구매 국가와 수령 국가가 달라도 귀국 후 국내 택배/직접 전달만 선택하며, 여행자의 출발 국가와 수령 국가가 같아야 함.
6. 서로 다른 장소 묶음의 전체 rollback.
7. 같은 장소라도 한 요청이 유효하지 않으면 전체 rollback.
8. 정상 묶음의 개별 제안 생성과 중복 requestId 차단.
9. 동시에 제안 두 개를 선택해도 거래는 하나만 생성.
10. Mock 승인 실패 시 원장 미생성, 같은 승인 재시도는 한 번만 기록.
11. 구매 → 전달 준비 → 배송 → 수령 → 구매 확정 → 정산 전체 흐름과 중복 정산 방지.
12. 타인 증빙·보관금·대화 접근 차단.
13. 채팅 재시도의 중복 메시지 방지.
14. 분쟁 접수 시 보관금 FROZEN·정산 차단.
15. 구매 전 취소 시 Mock 결제금 전액 환불 상태.
16. 파일 저장소 재생성 시 데이터 유지·실패한 변경 rollback.
17. PostgreSQL DDL 적용·15개 seed 요청 적재·잘못된 FK/총액 거절.

## DOM 통합 시나리오

자동화는 소스를 모사한 별도 화면이 아니라 **실제로 export된 React Native Web JavaScript**를 실행한다.

- 온보딩 → 가상 세션 발급 → 예시 상품 링크 입력 → 새 요청 저장.
- 여행자 홈 → 시부야 묶음 선택 → 건당 보상 제안 전송.
- 구매자 제안 선택 → 모의 결제 → 상대 계정 전환 → 구매 증빙 → 배송 정보 등록 → 구매자 수령 → 구매 확정 → 여행자 정산.
- 해당 흐름의 React runtime error 없음.

## 확인하지 못한 범위

- 이 실행 환경의 브라우저는 로컬 주소 연결이 차단되어 실제 브라우저 클릭·스크린샷·픽셀 단위 레이아웃 검증은 완료하지 못했다. jsdom은 이를 대신했다고 주장하지 않는다.
- Xcode/Gradle 네이티브 빌드, 앱 설치·실기기 입력/권한/키보드/접근성 테스트는 미실행이다. native export 성공만 확인했다.
- Docker PostgreSQL 서버와 Redis의 실제 컨테이너 통합은 미실행이다. PostgreSQL SQL 구문·제약은 embedded PostgreSQL 엔진에서 검증했다.
- 실 OAuth·휴대폰/계좌 인증·PG·외부 지도·S3·외부 상품 크롤링·관세/국제 운송은 미연결·미검증이다.
- 30초 등록·1분 일정 등록은 UX 목표이며 사용자 실험으로 측정한 결과가 아니다.
